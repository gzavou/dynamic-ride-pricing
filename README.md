# Dynamic Ride Pricing Analysis 

**Authors:** Georgia Zavou, Ilaria Curzi, Theodoros Lambrou

## Project Overview
This project explores a dataset with dynamic ride pricing. The dataset uses **unit-based pricing** (currency unspecified) and does **not include location information**. Our goal is to analyze the data and identify which features influence dynamic pricing the most.

## Aim
- Investigate patterns in ride pricing  
- Identify key features that affect dynamic price fluctuations  
- Provide insights that could help optimize pricing strategies

## Features & Highlights
- Data cleaning and preprocessing pipelines  
- Exploratory data analysis (EDA) with visualizations  
- Feature importance analysis using statistical and ML methods  

## Technologies & Tools
- Python (Pandas, NumPy, Matplotlib, Seaborn)  
- Jupyter Notebooks for EDA and modeling
